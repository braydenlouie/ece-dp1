## 6. Logic Circuit

```
                         ┌───────────────────────────────────┐
                         │                                   │
  A ─────────────────────┤───────────┐                       │
                         │           │                       │
  B ───────┬─────────────┤──┐        │                       │
           │             │  │        │                       │
      ┌────┴────┐        │  │        │                       │
      │  NOT    │        │  │        │                       │
      │ (B')    │        │  │        │                       │
      └────┬────┘        │  │        │                       │
           │             │  │        │                       │
  C ───────┼─────────────┤──┼────────┤──┐                    │
           │             │  │        │  │                     │
  D ───────┼──────┬──────┤──┤────────┤──┤                    │
           │      │      │  │        │  │                     │
           │ ┌────┴────┐ │  │        │  │                     │
           │ │  NOT    │ │  │        │  │                     │
           │ │ (D')    │ │  │        │  │                     │
           │ └────┬────┘ │  │        │  │                     │
           │      │      │  │        │  │                     │
         ┌─┴──────┴─┐  ┌┴──┴─┐  ┌──┴──┴──┴─┐                │
         │  2-input  │  │2-in │  │  3-input  │                │
         │   AND     │  │ AND │  │   AND     │                │
         │  (B'D')   │  │(BD) │  │  (ABC)   │                │
         └─────┬─────┘  └──┬──┘  └────┬─────┘                │
               │            │          │                      │
            ┌──┴────────────┴──────────┴──┐                   │
            │        3-input OR           │                   │
            │    F = B'D' + BD + ABC      │                   │
            └──────────────┬──────────────┘                   │
                           │                                  │
                         F ●                                  │
```

**Detailed Circuit Description:**

```
         B ──►[ NOT ]──► B'
         D ──►[ NOT ]──► D'

         B' ──►┐
               ├──[ AND₁ ]──► B'D'
         D' ──►┘

         B ───►┐
               ├──[ AND₂ ]──► BD
         D ───►┘

         A ───►┐
         B ───►┤──[ AND₃ ]──► ABC
         C ───►┘

         B'D' ──►┐
         BD   ──►┤──[ OR ]──► F
         ABC  ──►┘
```

**Gate count:** 2 NOT gates, 3 AND gates (two 2-input, one 3-input), 1 OR gate (3-input) = **6 gates total**

## 8. Verilog Implementation

### Design Module

```verilog
//-----------------------------------------------------------------------------
// Module: sop_function
// Description: Implements F(A,B,C,D) = B'D' + BD + ABC
//              Minterms: 0, 2, 5, 7, 8, 10, 13, 14, 15
//              A = MSB, D = LSB
//-----------------------------------------------------------------------------
module sop_function (
    input  wire A,
    input  wire B,
    input  wire C,
    input  wire D,
    output wire F
);

    // Internal wires for intermediate signals
    wire B_not;      // B'
    wire D_not;      // D'
    wire term1;      // B'D'
    wire term2;      // BD
    wire term3;      // ABC

    // NOT gates
    not U1 (B_not, B);        // B' = NOT(B)
    not U2 (D_not, D);        // D' = NOT(D)

    // AND gates
    and U3 (term1, B_not, D_not);   // term1 = B'D'
    and U4 (term2, B, D);           // term2 = BD
    and U5 (term3, A, B, C);        // term3 = ABC

    // OR gate (final output)
    or  U6 (F, term1, term2, term3); // F = B'D' + BD + ABC

endmodule
```
